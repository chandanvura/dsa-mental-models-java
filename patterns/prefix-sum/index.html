Prefix Sum

Pay once for cumulative totals; answer ranges by subtraction.

Layman mental model

A running bank balance lets you calculate spending between dates.

When your brain should select this

range sumsubarray summany queriesbalance counts

How the algorithm moves

1

Build prefix[i+1] as sum through i.

2

For [L,R], subtract prefix[L] from prefix[R+1].

3

Combine prefix values with a HashMap for target sums.

Cost of the approach

Best

O(n) build, O(1) query

Average

O(n)

Worst

O(n)

Space

O(n)

{}Java reference

static int rangeSum(int[] prefix, int left, int right) {
  return prefix[right + 1] - prefix[left];
}
static int[] prefix(int[] a) {
  int[] p=new int[a.length+1];
  for(int i=0;i<a.length;i++) p[i+1]=p[i]+a[i];
  return p;
}

Say this in the interview

“A range sum contains two prefixes. Subtracting the part before L leaves exactly the values from L through R.”

Mistakes to avoid

  • Off-by-one errors
  • Prefix sums can overflow int for large values
